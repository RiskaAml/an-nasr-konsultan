# An Nasr Blueprint

Website Company Profile CV. AN NASR KONSULTAN

1. Project Overview

Buat sebuah website Company Profile modern untuk CV. AN NASR KONSULTAN, perusahaan yang bergerak di bidang jasa konsultansi teknik sipil, perencanaan, pengawasan, perizinan, dan konstruksi yang berlokasi di Kabupaten Jombang, Jawa Timur.

Website bertujuan untuk meningkatkan kredibilitas perusahaan, memperkenalkan layanan, menampilkan portofolio proyek, dan memudahkan calon klien menghubungi perusahaan.

Website harus menggunakan Bahasa Indonesia secara penuh.

Jangan gunakan Lorem Ipsum maupun dummy text. Buat copywriting yang relevan dengan perusahaan konsultan konstruksi.

24. Catatan Penting

Seluruh antarmuka menggunakan Bahasa Indonesia.

Jangan menyalin desain website referensi, tetapi gunakan sebagai inspirasi alur dan kualitas visual.

Ciptakan identitas visual yang berbeda dengan nuansa biru modern, layout yang lebih lega, penggunaan whitespace yang baik, dan elemen visual yang lebih premium.

Fokus utama adalah membangun kepercayaan calon klien melalui tampilan profesional, navigasi yang mudah, serta penyajian layanan yang jelas dan meyakinkan.

Pastikan website terasa seperti milik perusahaan konsultan teknik dan konstruksi berskala profesional, bukan template generik.
